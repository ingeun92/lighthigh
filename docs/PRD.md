# lighthigh — PRD v1 (MVP)

> 흩어진 월드컵 하이라이트를, 일정표에서 한 번의 탭으로.
> 대상 대회: 2026 FIFA 북중미 월드컵 (~7/19). 대회 진행 중 출시 목표.

## 0. 조사로 확정된 전제 (data-source 검증 결과 반영)

- **일정/결과**: football-data.org 무료 tier (`/v4/competitions/WC/matches`). 라이브 스코어 불필요(끝난 경기 중심) → 초기 운영비 $0. 라이브 표시가 필요해지면 API-Football($19/월) 전환.
- **하이라이트**: YouTube Data API. `playlistItems.list`로 KBS/JTBC 공식 채널 업로드 순회(quota 거의 무료) → 키워드 필터 → `videos.list`로 `embeddable` 확인 → 관리자 승인.
- **치지직**: 공식 임베드/자동수집 **불가**. `chzzk.naver.com/video/{id}` 외부 딥링크 + 수동 큐레이션만.
- **핵심 리스크**: 방송사 영상이 임베드 차단(`embeddable:false`)일 수 있음 → **"외부 이동 + 완벽한 스크롤 복원"을 1순위 UX로 설계**. 임베드는 가능할 때의 보너스.

## 1. 목표 / 비목표

**목표 (MVP)**
1. 날짜별 경기 일정을 모바일에서 한 눈에 (KST, 라운드/조, 스코어, 상태)
2. 끝난 경기 → 하이라이트로 한 번의 탭에 연결
3. 하이라이트 시청 후 보던 위치로 매끄럽게 복귀
4. PWA(홈 화면 추가), 모바일 우선

**비목표 (v1 이후)**
- 로그인/회원, 즐겨찾기 팀, 푸시 알림, 검색/필터, 댓글, 다국어, 영상 자체 호스팅, 실시간 라이브 스코어

## 2. 사용자 & 핵심 시나리오

- **타겟**: 본방 사수 못 하고 결과·하이라이트만 빠르게 챙기는 모바일 사용자.
- **핵심 플로우**:
  1. 진입 → 오늘/가장 가까운 경기로 자동 위치
  2. 경기 카드의 스코어 + `[하이라이트]` CTA
  3. 탭 → (임베드 가능) 인앱 모달 재생 / (불가) 외부 딥링크
  4. 닫기/뒤로 → 보던 카드 위치 그대로

## 3. 정보 구조 (화면)

| 화면 | 설명 |
|---|---|
| **홈 (일정)** | 날짜 섹션으로 그룹된 경기 리스트. 상단 날짜 칩 네비. 진입 시 오늘로 스크롤 |
| **경기 카드** | 국기·팀명·스코어·상태·KST 킥오프·라운드. 종료 시 하이라이트 CTA |
| **하이라이트 뷰어** | 임베드 가능: 인앱 모달 iframe / 불가: 외부 링크 바텀시트(유튜브·치지직 선택) |
| **(관리자) 매핑** | 자동 수집된 후보를 경기에 매핑·승인. `embeddable` 표시. 치지직 수동 입력 |

## 4. 기능 요구사항

### F1. 경기 일정 리스트
- 날짜(KST)별 그룹, 섹션 헤더(예: `6월 16일 (월)`)
- 카드: 홈/원정 국기·국가명(ko), 스코어(종료 시), 상태 배지(예정/진행중/종료), KST 시각, 라운드/조
- 진입 시 오늘 또는 가장 가까운 미래 경기로 스크롤
- 상단 날짜 칩으로 점프

### F2. 하이라이트 연결
- 경기당 하이라이트 0..N개(소스: youtube/chzzk)
- **연결 우선순위**: 임베드 가능 유튜브 → 직링크 유튜브 → 치지직 딥링크
- 임베드 가능 유튜브: 인앱 모달(`youtube.com/embed/{id}`), iframe `onError`(101/150) 시 직링크 폴백
- 그 외: 외부 새 탭/딥링크(`rel="noopener"`). 모바일 치지직은 웹 URL(`chzzk.naver.com/video/{id}`)
- 하이라이트 미등록 경기: CTA 비활성 + "하이라이트 준비 중"

### F3. 매끄러운 왕복 (차별화 포인트)
- SPA 라우팅, **스크롤 위치 복원**(외부 이동 후 복귀 시 보던 카드 그대로)
- 인앱 모달은 라우트 이탈 없이 오버레이 → 닫으면 즉시 동일 위치
- PWA standalone에서 외부 링크 복귀 시 상태 유지

### F4. PWA
- manifest + 아이콘, 홈 화면 추가, 오프라인 시 마지막 캐시 일정 표시(선택)

### F5. 관리자 매핑 (반자동 운영)
- 후보 큐(자동 수집) 목록 → 경기 선택 → 승인/거부
- `embeddable` 뱃지로 임베드/직링크 구분
- 치지직 링크 수동 입력 폼

## 5. 데이터 동기화 (Cron)

- **일정 동기화**: football-data WC matches → upsert (경기 6시간/대회중 1시간 주기)
- **하이라이트 수집**: 채널 uploads 순회 → 키워드 필터 → `videos.list(status)` → 후보 큐 insert (6시간 주기, 경기 종료 직후 집중)
- quota 예산: 일 50~550 units (무료 10,000 내 충분)

## 6. 비기능 요구사항
- 모바일 우선, 첫 화면 LCP < 2.5s (ISR/캐시)
- 운영비 $0 출발 (유료 전환은 라이브 스코어 도입 시)
- YouTube 메타데이터 30일 보관 정책 준수, 영상 다운로드/광고우회 금지

## 7. 성공 지표 (가설)
- 진입 → 하이라이트 탭 전환율
- 하이라이트 1개 이상 매핑된 종료 경기 비율(커버리지)
- 복귀 후 추가 경기 탐색률(왕복 UX 효과)
