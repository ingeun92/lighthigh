## 화면 흐름

```
 [홈/일정] ──탭(종료경기 CTA)──▶ 하이라이트 연결 분기
     ▲                              │
     │                    embeddable?┤
     │              ┌────── yes ─────┴───── no ──────┐
     │       [인앱 모달 재생]              [외부 링크 바텀시트]
     │              │                              │
     └──닫기(스크롤복원)──┘            외부 이동 → 뒤로(스크롤복원)─┘

 [Cron] football-data ─▶ matches DB
 [Cron] YouTube uploads ─▶ 후보 큐 ─▶ [관리자 승인] ─▶ highlights DB ─▶ 홈
```

## 상호작용 원칙
- **스크롤 복원이 최우선**: 임베드 여부와 무관하게 "탭→보고→돌아오면 그 자리".
- 임베드 모달은 history state 로 열어 안드로이드 뒤로가기로 닫힘.
- 외부 링크는 항상 `rel="noopener noreferrer"`, 새 탭/딥링크.
- CTA 상태: 활성(하이라이트 있음) / 비활성("준비 중") 명확히 구분.
